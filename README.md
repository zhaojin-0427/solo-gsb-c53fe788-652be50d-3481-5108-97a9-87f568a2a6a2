# 曝光包围照片去重影合成台

上传 3～7 张同场景、同尺寸、固定光圈 / ISO / 白平衡的包围曝光 JPEG，输入各自的
快门时间并选定参照帧，服务端自动完成配准、运动去重影与 HDR 合成，输出
色调映射后的成片 PNG 与不确定区域遮罩。

## 功能特性

- **自动配准**：ORB 特征 + 部分仿射估计（旋转 / 平移 / 缩放），CLAHE 预增强
  削弱帧间曝光差异；低纹理画面自动回退到梯度域 ECC 配准。
- **静态区域 HDR 融合**：sRGB 线性化后按快门时间换算辐射度，用帽式权重
  （裁切处权重为 0）加权融合，从短曝光恢复高光、从长曝光恢复暗部。
- **运动去重影**：运动物体只保留参照帧位置的内容。即使参照帧在旧位置过曝、
  两张非参照帧都在旧位置拍到同一物体，也不会把旧物体当作高光细节留下——
  参照帧是动态内容的唯一来源。
- **不误判**：曝光差异按快门时间补偿；饱和裁切像素不参与运动比较；配准残差
  通过模糊比较 + ±1px 邻域包络吸收，不会被当作运动。
- **不确定标注**：全组曝光都缺失细节、或无法可靠判断的区域（含重叠区外、
  动态且参照已裁切的区域）保留参照内容，并在遮罩中标白。
- **重叠不足不输出**：配准后公共重叠区域低于 50% 时报错，不生成成片。
- **输入校验**：非法快门时间（非有限正数）、损坏图片、尺寸不一致、
  张数不符、参照索引越界均返回明确错误。

## 快速开始（Docker Compose）

```bash
docker compose up --build
```

启动后访问 <http://localhost:8000> 。

### 使用流程

1. 点击上传区选择 3～7 张 JPEG；
2. 为每张填写快门时间（秒），支持 `1/250`、`0.004`、`2` 等写法；
3. 选择一张作为参照帧（默认中间一张）；
4. 点击「开始合成」；
5. 页面并排展示**参照帧 vs 合成成片**，并提供：
   - **下载成片 PNG**（色调映射后的 8-bit 图像）
   - **下载不确定遮罩 PNG**（白色 = 不确定区域，保留参照内容）

产物也可直接通过 API 下载（见下）。

## API

### `POST /api/merge`

`multipart/form-data`：

| 字段 | 说明 |
| --- | --- |
| `files` | 3～7 个 JPEG 文件（重复字段） |
| `shutter_times` | JSON 数组，各张快门时间（秒），如 `[0.004, 0.016, 0.032]` |
| `reference_index` | 参照帧索引（从 0 开始） |

成功返回 `200`：

```json
{
  "job_id": "f42b9c70e2dd",
  "meta": { "width": 320, "height": 240, "overlap": 0.975,
            "dynamic": 0.051, "uncertain": 0.059, "...": "..." }
}
```

输入非法返回 `400`，`detail` 为中文错误说明（非法快门、图片损坏、
尺寸不一致、张数不符、配准失败、重叠不足等）。

### `GET /api/jobs/{job_id}/{kind}`

下载产物，`kind` 取值：

- `result` — 合成成片 PNG
- `mask` — 不确定遮罩 PNG（白 = 不确定）
- `reference` — 参照帧 PNG
- `meta` — 统计信息 JSON

示例：

```bash
curl -OJ http://localhost:8000/api/jobs/f42b9c70e2dd/result
curl -OJ http://localhost:8000/api/jobs/f42b9c70e2dd/mask
```

## 算法说明

1. **配准**：所有帧向参照帧估计部分仿射变换并 warp 对齐；统计公共重叠
   区域，低于阈值（50%）直接报错不输出。
2. **运动分类**（在参照曝光域、线性空间中逐像素进行）：
   - 参照与该帧均未裁切：比较曝光补偿后的差异（带 ±1px 邻域包络与
     模糊容差），显著不一致判为动态；
   - 参照高光裁切：静态场景在其它帧中应同样明亮，若补偿后明显偏暗，
     说明内容已变化（如物体移走后露出的背景），判为动态——这保证了
     "旧位置的物体"即使被多张非参照帧拍到也不会被留下；
   - 参照暗部裁切：对称地，补偿后明显偏亮判为动态。
3. **融合**：静态区域按帽式权重融合全部未裁切曝光的辐射度估计；
   动态区域只取参照帧内容。
4. **不确定区域**：重叠区外、动态且参照已裁切、全组均无有效曝光的像素，
   保留参照内容并写入遮罩。
5. **色调映射**：自动关键值 + 全局 Reinhard + sRGB 编码，输出 8-bit PNG。

## 说明与限制

- 输入需固定光圈、ISO、白平衡，仅快门不同；本工具按快门时间做曝光补偿，
  并假设 sRGB 响应曲线做线性化（未做相机响应曲线标定）。
- 配准模型为部分仿射（平移 + 旋转 + 统一缩放），适用于手持轻微抖动，
  不处理大幅视差或镜头畸变。
- 处理分辨率上限 3000px（超长边整体降采样），可在 `pipeline.py` 的
  `MAX_DIM` 调整。
- 结果保存在 `backend/results/`（Docker 中为命名卷 `hdr_results`），
  重启后仍可下载；清理旧结果需手动删除。
